Other extension permissions

  • Side panel: display ChatGPT inside Singularity.
  • Tabs and active tab: identify the current page and run actions you explicitly start.
  • Storage: remember settings, pending requests, and progress.
  • Clipboard: copy ChatGPT responses and paste content into wiki pages.
  • Context menus: provide Send to Singularity actions when right-clicking.
  • Website access: interact with ChatGPT, AppLimit, and the configured local development sites.
